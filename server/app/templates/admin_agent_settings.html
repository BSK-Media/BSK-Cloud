Google Search Console i Google Analytics

{% if google_email %}● podłączone{% else %}niepodłączone{% endif %}

Agent co dobę porównuje kliknięcia, wyświetlenia i średnią pozycję w Google oraz odwiedziny i konwersje z Google Analytics 4 z poprzednim tygodniem i zgłasza spadki. Jedno konto usługi obsługuje obie usługi.

{% if google_email %}

Konto usługi: {{ google_email }} — dodaj ten adres w Search Console każdego klienta (Ustawienia → Użytkownicy i uprawnienia → Dodaj użytkownika, uprawnienie „Ograniczone”) i w Google Analytics 4 (Administracja → Zarządzanie dostępem do usługi → + → Dodaj użytkowników, rola „Wyświetlający”).

{% endif %}
Jak zdobyć klucz (jednorazowo, ok. 10 minut)
  1. Wejdź na console.cloud.google.com i utwórz projekt, np. „BSK Agent”.
  2. Interfejsy API i usługi → Biblioteka → włącz Google Search Console API.
  3. Interfejsy API i usługi → Dane logowania → Utwórz dane logowania → Konto usługi, nazwa np. „bsk-agent”.
  4. Otwórz konto usługi → Klucze → Dodaj klucz → JSON. Pobierze się plik — otwórz go w Notatniku i wklej całą zawartość poniżej.
  5. Adres e-mail konta usługi (kończy się na .iam.gserviceaccount.com) dodaj w Search Console klientów.
  6. Przy każdej stronie klienta w agencie wpisz nazwę usługi z Search Console, np. sc-domain:klient.pl albo https://www.klient.pl/.

Google Analytics 4 (to samo konto usługi):

  1. W Google Cloud: Biblioteka → włącz Google Analytics Data API.
  2. W Google Analytics klienta: Administracja → Zarządzanie dostępem do usługi → + → Dodaj użytkowników — adres konta usługi, rola Wyświetlający.
  3. Tam też: Administracja → Szczegóły usługi — skopiuj Identyfikator usługi (same cyfry) i wpisz go przy stronie klienta w agencie (sekcja Integracje).

WordPress i WooCommerce

Dane dostępowe wpisujesz przy każdej stronie klienta (Agent AI → Strony klientów → nazwa strony → Integracje). Wszystko tylko do odczytu:

  • WordPress: w panelu WordPress klienta Użytkownicy → Profil → Hasła aplikacji — wpisz nazwę „BSK Agent” i skopiuj wygenerowane hasło (konto administratora). Agent widzi wtyczki i ich wersje.
  • WooCommerce: WooCommerce → Ustawienia → Zaawansowane → REST API → Dodaj klucz, uprawnienia „Odczyt”. Agent widzi wersję PHP, aktualizacje wtyczek i zamówienia (nieudane, spadek sprzedaży).

Sieć biurowa (SNMP)

Urządzenia dodajesz na stronie Agent AI → Sieć biurowa. Żeby agent widział restarty i stan portów, włącz SNMP v2c w urządzeniu (w Ruijie: Obszar roboczy → SNMP) i wpisz to samo „community” (np. public). Bez SNMP agent sprawdza tylko, czy urządzenie odpowiada.
